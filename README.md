# spb-fireworks-ics

Календарь праздничных салютов и городских праздников Санкт-Петербурга в формате `.ics` (RFC 5545).

Подпишитесь — и все салюты СПб автоматически появятся в вашем календаре.

---

## Что внутри

Календарь покрывает ежегодные события СПб:

- 27 января, 21:00 — годовщина снятия блокады Ленинграда, салют
- 23 февраля, 21:00 — День защитника Отечества, салют
- 8 марта — государственный праздник
- 9 мая, 22:00 — День Победы, главный салют
- 27 мая — День города, концерты + салют 23:55
- 12 июня, 22:00 — День России, салют
- Последняя суббота июня — Алые паруса (ночь выпускников, фейерверк ~00:40)
- Последнее воскресенье июля — День ВМФ, военно-морской парад + салют
- 4 ноября — День народного единства

Плюс федеральные выходные/праздники/предпраздничные дни (для прозрачности переносов).

## Как подписаться

### macOS
Календарь → Файл → Новая подписка на календарь → вставить URL.

### iPhone/iPad
Настройки → Календарь → Учётные записи → Другое → Календарь по подписке → вставить URL.

### Android / Google Calendar
На телефоне через UI подписаться нельзя. Вариант:
1. Откройте `calendar.google.com` на компьютере.
2. Настройки → Добавить календарь → Импортировать → выберите скачанный `.ics` файл.

Или загрузите `.ics` в любой другой клиент (DigiCal, aCalendar, etc.) через «импорт».

### Thunderbird / Outlook
Файл → Импорт → iCalendar → выберите `.ics`.

## URL подписки

Раз в месяц GitHub Actions обновляет файл `spb-fireworks.ics` и коммитит его обратно в репозиторий.
Прямая ссылка:

```
https://raw.githubusercontent.com/thegalkin/spb-fireworks-ics/main/spb-fireworks.ics
```

Если вы подписались по этому URL, изменения применяются автоматически.

## Источники

| Что | Откуда |
|---|---|
| Фиксированные салюты СПб (9 мая, День города, День ВМФ, Алые паруса и т. д.) | Комитет по культуре Санкт-Петербурга, peterburg2.ru (агрегатор) |
| Федеральные праздники, выходные, переносы | [nikitastupin/prodcal_ics](https://github.com/nikitastupin/prodcal_ics) (MIT, обновляется ежегодно) |

Перенос выходного на другой день **не отменяет** сам праздник и салют. Алые паруса
и День ВМФ рассчитываются по правилам, а не берутся из upstream — потому что город
объявляет их отдельно.

## Важные оговорки

- Дата и время салюта — **оценочные ±сутки**. Город обычно подтверждает за 1–2
  недели до события. Следите за официальными анонсами Комитета по культуре.
- Алые паруса: точная дата объявляется Смольным в мае-июне. Календарь использует
  последнюю субботу июня как стабильное правило (для 2026 — 27.06, для 2027 —
  26.06). В годы, когда город сдвигает дату, нужно открыть PR с правкой.
- День ВМФ с 2025 года официально отмечается в **последнее воскресенье июля**
  (ФЗ-419 от 25.12.2023).

## Зачем нужен этот репозиторий

- Один `.ics` URL — добавил и забыл.
- Без LLM, без аккаунтов, без регистрации.
- Открытый исходник (MIT), форкни и подправь под свой город, если ты не из СПб.
